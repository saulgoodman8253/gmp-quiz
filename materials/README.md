# 강의자료 보관 폴더

문항을 만들고 고칠 때 근거로 쓰는 원본 자료를 두는 곳입니다. 앱 화면에서는 이 폴더를 읽지 않습니다.

## 넣는 방법

| 자료 | 파일 이름 예시 |
| --- | --- |
| 강의 PDF | `wk02_upstream1.pdf` |
| 강의 녹음 텍스트 | `wk02_transcript.txt` (가능하면 `[01:32]` 같은 시간 표시 포함) |

주차 번호(`wk02`)를 파일 이름 앞에 붙이면 어느 문제 파일(`questions/wk02.json`)과 연결되는지 바로 알 수 있습니다.

> 저장소가 공개(public)라면 여기 올린 파일도 누구나 볼 수 있습니다. 공개하면 안 되는 강의자료라면 저장소에 올리지 말고 대화에 직접 첨부해 주세요.

## 문항 작성 원칙

- 시험지 형식, 한국어 **5지선다**
- 개념 암기보다 **공정 전체 흐름**(세포은행 → 씨드 확장 → 생산 배양 → 수확 → 하류 공정 → 품질 관리)을 이해해야 풀 수 있는 문항 위주
- 유형: 상황판단 · 계산 · 연결 · 개념
- 모든 문항의 `source` 에 PDF 쪽수(예: `p.62-66`)와 녹음 시간(예: `강의 01:32`)을 적고, 해설에서 근거를 설명
- 새 자료가 들어오면 기존 문항의 출처·내용을 자료에 맞게 고치고 새 문항을 추가 (기존 `id` 는 유지)
