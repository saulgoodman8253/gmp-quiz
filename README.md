# GMP 복습 문제집

바이오플랜트 GMP 운영 과목 복습용 객관식 문제집 웹 앱입니다.
휴대폰·태블릿·PC 브라우저에서 바로 쓸 수 있고, 빌드 도구 없이 HTML·CSS·JavaScript만으로 되어 있어 GitHub Pages에 그대로 올리면 됩니다.

## 주요 기능

| 기능 | 설명 |
| --- | --- |
| 📖 단원별 학습 | 고른 주차만 한 문제씩 풉니다. 답을 고르면 바로 정답/오답, 해설, 출처(PDF 쪽수·강의 시간)가 나옵니다. |
| 📝 단원 시험 | 고른 주차를 **시험지 형식**으로 끝까지 푼 뒤 한꺼번에 채점합니다. |
| 🎯 전범위 모의고사 | 등록된 모든 주차에서 출제하는 시험지 형식 모의고사입니다. |
| ❗ 오답 노트 | 틀린 문항은 자동 저장되고, "오답만 다시 풀기"로 다시 풀 수 있습니다. 맞히면 오답 노트에서 빠집니다. |
| 🆕 미출제 문항 우선 | 아직 한 번도 나오지 않은 문항을 매 회차 우선 포함합니다(시험지 머리에 "미출제 n문항 포함" 표시). |
| 📊 기록 | 회차별 점수와 주차별 누적 정답률을 결과 화면과 "학습 기록 보기"에서 확인합니다. |
| 🔀 무작위 섞기 | 문항 순서와 보기 순서를 매번 섞습니다. 섞어도 정답 판정은 정확합니다. |
| 🌓 다크 모드 | 기기 설정을 따르며, 오른쪽 위 버튼으로 자동/다크/라이트를 바꿀 수 있습니다. |

기록과 오답 노트는 **각 기기의 브라우저(localStorage)** 에 저장됩니다. 휴대폰과 PC의 기록은 서로 공유되지 않습니다.

## GitHub Pages 켜는 방법

1. GitHub에서 이 저장소로 들어갑니다.
2. 위쪽 메뉴의 **Settings** → 왼쪽 메뉴의 **Pages** 를 누릅니다.
3. **Build and deployment** 의 **Source** 를 **Deploy from a branch** 로 둡니다.
4. **Branch** 에서 배포할 브랜치(보통 `main`)와 폴더 **`/ (root)`** 를 고르고 **Save** 를 누릅니다.
5. 1~2분 뒤 같은 화면 위쪽에 주소가 나옵니다. 보통 `https://<사용자이름>.github.io/gmp-quiz/` 입니다.
6. 휴대폰에서 이 주소를 연 뒤 공유 메뉴의 **홈 화면에 추가** 를 누르면 앱처럼 쓸 수 있습니다.

> 저장소가 비공개(private)라면 무료 계정에서는 Pages를 쓸 수 없습니다. 공개 저장소로 바꾸거나 유료 플랜이 필요합니다.

## 문제 파일 추가 방법

1. `questions/` 폴더에 새 JSON 파일을 만듭니다. 예: `questions/wk03.json`
2. 아래 형식으로 문항을 적습니다.
3. `questions/index.json` 의 `files` 목록에 **파일 이름만** 추가합니다.

```json
{
  "files": [
    "wk02.json",
    "wk03.json"
  ]
}
```

저장하고 GitHub에 올리면 시작 화면의 주차 범위에 자동으로 나타납니다.

### 문제 JSON 형식

```json
{
  "week": "WK03",
  "title": "Upstream Process 2",
  "questions": [
    {
      "id": "wk03-001",
      "type": "상황판단",
      "question": "문제 본문 (줄바꿈은 \n)",
      "choices": ["보기1", "보기2", "보기3", "보기4", "보기5"],
      "answer": 2,
      "explanation": "해설",
      "source": "p.62-66, 강의 01:32"
    }
  ]
}
```

- `answer` 는 **1부터 시작하는 번호**입니다(첫 번째 보기 = 1). 보기를 섞어도 앱이 알아서 정답 위치를 맞춰 줍니다.
- `choices` 는 4개(4지선다)도 5개(5지선다)도 됩니다. 시험 대비용 문항은 5지선다로 만듭니다.
- `type` 은 `상황판단`, `계산`, `연결`, `개념` 중 하나를 씁니다.
- `id` 는 전체 파일에서 겹치지 않아야 합니다(겹치면 뒤의 문항은 건너뜀). 오답 노트·출제 이력이 이 `id`로 저장되므로, 한 번 정한 `id`는 바꾸지 않는 것이 좋습니다.
- `source` 에는 강의 PDF 쪽수와 녹음 시간을 적습니다. 해설 아래에 "📄 출처"로 표시됩니다.
- 형식이 틀린 문항이 있으면 시작 화면 위에 어떤 파일의 어떤 문항이 문제인지 표시됩니다.

## 현재 문제 구성

| 파일 | 범위 | 문항 | 주요 근거 |
| --- | --- | --- | --- |
| `wk02.json` | Upstream (배양) | 23 | WK02 PDF + 2주차 녹음 |
| `wk03.json` | Downstream 1 (크로마토그래피) | 23 | WK03 PDF + 3주차 녹음 |
| `wk04.json` | 바이오공정 개관 · Downstream 2 (여과) | 41 | 4주차 녹음 + WK04 여과 PDF(슬라이드 80~160) |
| `wk05.json` | 완제 · RABS · APS · Isolator | 19 | WK05 PDF 2종 + 5주차 녹음 |
| `wk06.json` | mAb 공정 설계 · 여과 · 공정 계산 | 20 | WK06 PDF + 6주차 녹음 |
| `wk07.json` | GMP Engineering | 21 | WK07 PDF + 7주차 녹음 |

- 출처의 `p.N` 은 PDF 뷰어 기준 쪽수입니다(WK03은 스캔본이라 인쇄된 쪽 번호 + 1) WK04 여과 PDF는 슬라이드 아래쪽 `Page / N` 번호로 적었습니다. 녹음 시간은 `N주차 녹음 (1부/2부) hh:mm` 형식입니다.
- 7주차 녹음 2부 49:16~59:13의 시험 범위 리뷰에서 언급된 주제를 우선해 출제했습니다. 슬라이드에 X 표시가 된 쪽은 출제 근거에서 뺐습니다.

## 강의자료·녹음본으로 문제 늘리기

`materials/` 폴더에 강의 PDF와 강의 녹음 텍스트를 올려 두면, 그 내용을 바탕으로 `questions/wkXX.json` 문항을 만들거나 고칠 수 있습니다. 자세한 방법은 [`materials/README.md`](materials/README.md)를 보세요.

## 내 컴퓨터에서 미리 보기

`index.html` 을 더블클릭해서 열면(file://) 브라우저 보안 정책 때문에 문제 파일을 불러오지 못합니다. 저장소 폴더에서 간단한 서버를 띄워 여세요.

```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 열기
```

## 파일 구성

```
index.html          화면 뼈대
style.css           디자인 (모바일 우선, 다크 모드)
app.js              동작 (문제 불러오기, 채점, 기록)
questions/
  index.json        사용할 문제 파일 목록
  wk02~wk07.json    주차별 문항
materials/          강의 PDF·녹음 텍스트 보관 (앱에서는 쓰지 않음)
.nojekyll           GitHub Pages가 파일을 그대로 배포하게 함
```
